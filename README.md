# RapidAssist AI

Real-time voice-based field assistance AI using Moss for fast semantic retrieval.

## Problem

Field workers often need quick access to equipment manuals,
safety procedures, and troubleshooting instructions.

## Solution

RapidAssist AI lets a field worker describe a problem using voice.
The system retrieves relevant trusted operational information using
Moss and provides context-aware assistance.

## Architecture

Voice Input → Speech-to-Text → RapidAssist Agent → Moss Retrieval
→ LLM Reasoning → Safety Validation → Text-to-Speech

## Tech Stack

- Python
- FastAPI
- Moss
- React
- WebSockets
- Speech-to-Text
- Text-to-Speech
- LLM
